# Senty_LP

Landing page e ambiente di prototipazione front-end di Senty.

**Versione corrente:** `SENTY-LP-v0.1.0`

## Stack

- React
- TypeScript
- Vite
- CSS nativo
- Vercel per la preview live

## Flusso di lavoro

- GitHub contiene codice, cronologia e versioni.
- `main` rappresenta la versione di riferimento.
- Vercel pubblica la preview live collegata al repository.
- Le iterazioni di design vengono identificate con una versione `SENTY-LP-vX.Y.Z`.

## Versioning

Usiamo Semantic Versioning con prefisso di progetto:

- `SENTY-LP-v0.1.0` — prima base navigabile;
- incremento **PATCH** (`0.1.1`) per correzioni e micro-affinamenti;
- incremento **MINOR** (`0.2.0`) per nuove sezioni, componenti o revisioni significative;
- `1.0.0` quando la landing sarà considerata pronta come prima release completa.

## Avvio locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
