# Senty

Prima base applicativa di Senty.

## Stack

- React
- TypeScript
- Vite
- CSS nativo

## Avvio locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Principi della V1

- due soli tool principali;
- navigazione immediata;
- contenuti in italiano;
- responsive come requisito di base;
- dipendenze ridotte al minimo;
- identity e microcopy facilmente iterabili.
