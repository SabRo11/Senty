# Senty_LP

Landing page e ambiente di prototipazione front-end di Senty.

**Versione corrente:** `SENTY-LP-v0.7.0`  
**Demo live:** https://senty-sigma.vercel.app

## Stato corrente

La `v0.7.0` consolida l’hero e porta il modulo Metodo verso una direzione visuale più fresca, pop e product-led, mantenendo Manrope, Blue Orchid e il sistema Senty.

### Cosa cambia in v0.7.0

1. contenuti hero inseriti in un box fill-width sulla griglia pagina, con radius Senty e gradiente usato come cornice;
2. headline “Ascolta tutto. Capisci cosa conta.” con reveal on-scroll;
3. voci del Metodo cliccabili oltre che scroll-driven;
4. Raccogli: fotografia lifestyle + UI multicanale Instagram / Google / Tripadvisor con feedback generici positivi, negativi e misti;
5. Analizza: nuova dashboard bento con visual dominante, sentiment, volume, temi e fonti, incluse micro-animazioni;
6. Comprendi: fotografia focalizzata su gesto/strumento + UI di insight e driver;
7. Confronta: grafico wide-screen senza fondale decorativo, con serie competitor e benchmark;
8. Restituisci: fotografia di lavoro collaborativo + output operativo Senty AI;
9. UI resa più pop tramite accenti lime, aqua, purple e orange, senza modificare la palette core.

## UI system

- font principale: **Manrope**;
- MuseoModerno solo per micro-accenti;
- Blue Orchid `#2B3DFA` e scala tonale Senty;
- navy `#171D70` / `#0D103A`;
- radius generosi e card morbide;
- fotografia fresca, con enfasi su gesti e props più che sui volti;
- motion concentrato sulle transizioni narrative e sui dati.

## Stack

React + TypeScript + Vite + CSS nativo. GitHub gestisce codice/versioni, Vercel il deploy automatico di `main`.

Decisioni e iterazioni sono documentate in `docs/ITERATIONS.md` e nei file di baseline/versione presenti in `docs/`.
